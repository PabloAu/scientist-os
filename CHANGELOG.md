# Changelog

## 0.1.0b1 — 2026-09-06

First experimental Scientist OS beta, derived from the reusable source workflow with new product history and generic code.

- Local browser UI, Python package and CLI with fictional microscopy/environmental examples.
- Fifteen record types, provenance links, hashes, revision history, atomic operations, named reviews and stale dependency invalidation.
- Bounded agent, deterministic demo, compatible API adapter and optional MCP harness.
- Independent-unit CSV summaries, independent-study fixed/random meta-analysis, SVG figures and scientific-risk screening.
- Evidence-led experiment, terminology, article and journal proposal tasks; editable human-reviewed drafts.
- Fourteen lifecycle stages, JSON/Markdown exports, manuals, source audit and evaluation protocol.

The source audit reproduced packet traversal and unsupported worker verification in an isolated copy. The new runtime replaces that writer. Integration checks corrected partial saves, stale figures, malformed CSV acceptance, invalid hosts and redaction/citation inconsistencies.

Live-model quality, shared hosting/accounts, PDF extraction, arbitrary code execution, literature acquisition, automatic publication, signed executables and laboratory validation are not claimed.
