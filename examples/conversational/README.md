# Fictional conversational research project

All experimental materials and study estimates in this folder are original
CC0-1.0 teaching fixtures. No experiments occurred and no cited fixture study is
a real publication. Numerical recovery is a software demonstration only.

Use `scripts/make_conversational_fixture.py` to create a mixed input folder with
a PDF, PowerPoint, notes, protocol, material inventory and CSV. Start from an
empty Scientist OS workspace and use the host skill to incorporate this folder.
Do not load a prewritten assistant answer. The acceptance prompts are in
`journeys.md`; tool calls, observations and failures belong in the evaluation log.

The software analysis module is separately versioned in Git under
`examples/pipelines/`; the executable run pins an immutable commit. For a real
scientific project, use its owning analysis repository and owner-described data.
